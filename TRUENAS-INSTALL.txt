================================================================================
  FLUXER BOT — TrueNAS Custom App environment variables
================================================================================

Git repo:  https://github.com/trolle6/Fluxer-TTS
Branch:    master
Compose:   docker-compose.yml

Storage:   Host path on your pool  →  Mount path /app/Data

--------------------------------------------------------------------------------
REQUIRED (bot will not start without these)
--------------------------------------------------------------------------------
  FLUXER_BOT_TOKEN          your Fluxer bot token
  OPENAI_API_KEY            your OpenAI API key

--------------------------------------------------------------------------------
RECOMMENDED (set these for full functionality)
--------------------------------------------------------------------------------
  FLUXER_CHANNEL_ID         main text channel ID (TTS reads from here by default)
  FLUXER_LOG_CHANNEL_ID     log channel ID
  FLUXER_MODERATOR_ROLE_ID  moderator role ID (Secret Santa admin commands)

--------------------------------------------------------------------------------
OPTIONAL (leave blank if you don't need them)
--------------------------------------------------------------------------------
  TTS_CHANNEL_ID            separate channel for TTS text only
                            (if blank, uses FLUXER_CHANNEL_ID)

  TTS_ROLE_ID               only members with this role can use TTS
                            (if blank, everyone in voice can use TTS)

  FLUXER_API_URL            only if not using official api.fluxer.app

  TTS_DEFAULT_VOICE         alloy, echo, nova, etc. (default: alloy)

  MAX_QUEUE_SIZE            TTS queue cap (default: 50)
  RATE_LIMIT_REQUESTS       TTS rate limit count (default: 15)
  RATE_LIMIT_WINDOW         TTS rate limit seconds (default: 60)
  MAX_TTS_CACHE             TTS audio cache entries (default: 50)
  AUTO_DISCONNECT_TIMEOUT   leave VC after idle seconds (default: 300)
  MAX_IMAGE_CACHE           DALL-E cache entries (default: 30)

  DEBUG_MODE                true / false (default: false)
  SKIP_API_VALIDATION       true / false (default: false)
  SS_DEBUG_START            allow /ss start when archive exists (default: false)

--------------------------------------------------------------------------------
NOT NEEDED IN TRUENAS UI
--------------------------------------------------------------------------------
  DATA_ROOT                 already set to /app/Data in compose

================================================================================

After editing env vars: Save → Upgrade/Redeploy (or Stop → Start).
