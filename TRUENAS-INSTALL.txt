================================================================================
  FLUXER BOT — TrueNAS (reliable config via config.env file on your HDD)
================================================================================

TrueNAS often does NOT pass Environment UI vars into the container.
Use a config.env file on your mounted storage instead.

Git repo:  https://github.com/trolle6/Fluxer-TTS
Branch:    master
Compose:   docker-compose.yml

--------------------------------------------------------------------------------
STEP 1 — Storage (pick your HDD / pool)
--------------------------------------------------------------------------------
  Host Path:   /mnt/YOURPOOL/apps/fluxer/data
  Mount Path:  /app/Data

--------------------------------------------------------------------------------
STEP 2 — Create config.env ON THE NAS (SSH or TrueNAS file manager)
--------------------------------------------------------------------------------

  sudo nano /mnt/YOURPOOL/apps/fluxer/data/config.env

Paste (fill in your values):

  FLUXER_BOT_TOKEN=paste_your_fluxer_token_here
  OPENAI_API_KEY=paste_your_openai_key_here
  FLUXER_CHANNEL_ID=your_channel_id
  FLUXER_LOG_CHANNEL_ID=your_log_channel_id
  FLUXER_MODERATOR_ROLE_ID=your_mod_role_id
  TTS_ROLE_ID=your_tts_role_id_if_you_use_one

Save the file.

Template in repo: WaveTechFluxerTTS/Data/config.env.example

--------------------------------------------------------------------------------
STEP 3 — Install / upgrade Custom App
--------------------------------------------------------------------------------
  Apps → Custom App → repo URL above
  Environment UI: leave empty (optional) — config.env is what matters
  Storage: as in step 1
  Install or Upgrade

--------------------------------------------------------------------------------
STEP 4 — Restart and check logs
--------------------------------------------------------------------------------
  Should NOT say "Missing FLUXER_BOT_TOKEN" anymore.

Optional vars: see config.env.example in the GitHub repo.

================================================================================
